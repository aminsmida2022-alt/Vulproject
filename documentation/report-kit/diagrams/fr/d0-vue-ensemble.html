n8n · Workflow 1
Pipeline de vulnérabilités (de A à Z)
  1. 1Scanner les 3 serveurs avec Trivy
  2. 2Attendre la fin du scan (vérification toutes les 45 s)
  3. 3Récupérer les résultats, supprimer les doublons
  4. 4Ajouter EPSS · CISA KEV · importance de l’actif · risques acceptés
  5. 5Calculer le score de chaque résultat P = 0,25·CVSS + 0,30·EPSS + 0,25·KEV + 0,20·Actif
  6. 6Envoyer les 917 résultats au tableau de bord
  7. 7Garder seulement P1/P2 (P ≥ 60) → créer, rouvrir ou ignorer un ticket
